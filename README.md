# Currículo do Arthur Morgan

Atividade de HTML: um currículo fictício do Arthur Morgan, de Red Dead Redemption 2, com referências e brincadeiras sobre o personagem.

O exercício usa títulos, parágrafos, listas, imagem e links, sem CSS ou JavaScript.

Para visualizar, abra [curriculo.html](curriculo.html) no navegador. A imagem depende de um endereço externo.
